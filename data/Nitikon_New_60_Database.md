# คลังข้อสอบนิติกร - ชุดใหม่ 60 รายการ

ข้อมูลสำหรับนำเข้าฐานข้อมูลอยู่ในบล็อก JSON เป็นอาร์เรย์ 60 รายการ แบ่งเป็น 4 หมวดตามต้นฉบับ

| ฟิลด์ | ความหมาย |
| --- | --- |
| `id` | รหัสไม่ซ้ำสำหรับนำเข้าฐานข้อมูล |
| `subject` | วิชา: นิติกร |
| `category` | ชุด/หมวดหมู่ตามต้นฉบับ |
| `source_question_number` | เลขข้อเดิม |
| `source_heading` | หัวข้อของข้อสอบ รวมเลขมาตรา ตามต้นฉบับ |
| `question` | คำถาม |
| `choices` | ตัวเลือก ก ข ค ง |
| `answer.choice` | ตัวเลือกที่ถูกต้องตามเฉลยต้นฉบับ |
| `answer.explanation` | เหตุผลและมาตราอ้างอิงตามต้นฉบับ |

คงเนื้อหาและอีโมจิพร้อมลิงก์เดิม ไม่แก้เลขมาตราหรือข้อกฎหมาย ต้นฉบับข้ามเลขข้อ 25 และมีข้อ 50 สองรายการ จึงคงทั้งสองรายการไว้โดยใช้ `id` ต่างกัน
